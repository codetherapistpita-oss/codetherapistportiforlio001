## How this project was developed

### Approach

The site is a **static portfolio** (no build step required) so it loads fast and deploys easily on **GitHub Pages**. Everything runs in the browser with **vanilla HTML, CSS, and JavaScript** — no React or Node server needed for hosting.

### Build process (step by step)

1. **Structure** — Single-page layout in `index.html`: welcome screen, hero, about, skills, projects, testimonials, contact, footer.
2. **Design & styling** — Custom CSS in `style.css`: dark/light themes, glass-style cards, animations, responsive breakpoints, custom cursor.
3. **Interactions** — JavaScript in `script.js`: theme toggle (saved in `localStorage`), typing effect, scroll reveals, project filters, mobile menu, contact form.
4. **CV** — Separate `cv.html` page with print-friendly layout; PDF export via **html2pdf.js** (download from the site nav).
5. **Assets** — Profile photos and project thumbnails in `Portfolio Picture/`; README previews in `screenshots/`.
6. **Branding** — Rebranded to **Code Therapist** with updated copy, stats (3+ years experience), tech stack, and contact links.
7. **Deploy** — Pushed to this repo; live on GitHub Pages at the URL below.

### Tools used while building

| Tool | Purpose |
|------|---------|
| **VS Code / Cursor** | Editing HTML, CSS, JS |
| **Git & GitHub** | Version control and hosting |
| **GitHub Pages** | Free static site hosting |
| **Formspree** | Contact form submissions |
| **html2pdf.js** | CV download as PDF |
| **Figma / browser DevTools** | Layout checks and UI polish |
